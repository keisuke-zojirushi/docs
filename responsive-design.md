# ZATI Responsive Design Standard

## Breakpoints

- Desktop: 1367px and above
- Laptop: 769px - 1366px
- Mobile: 768px and below

## Current implementation

### Model Search Results
- Desktop layout remains the baseline.
- Laptop layout keeps the table structure.
- Reduce padding and button size at laptop widths.
- Technical Information column is narrower.
- Mobile layout will be implemented separately.
