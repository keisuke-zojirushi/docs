\# ZATI Claude Instructions



このプロジェクトの開発ルールは `AGENTS.md` に記載されています。



Claudeは、ZATIのコードを確認・修正・提案する際に、必ず `AGENTS.md` の内容を優先して従ってください。



特に以下を守ってください。



\- 一度に大きな変更をしない

\- 既存の正常動作を壊さない

\- 修正するファイル名と場所を明確にする

\- ADD / DELETE / REPLACE を明確にする

\- 不明なコード構造を推測しない

\- Admin / ZAC TS / SVC のRole差を確認する

\- Themeだけでなく `zati-tools` Plugin側も考慮する

\- テスト結果を確認してから次の修正へ進む
